info Why I made this

This site is a small personal project where I keep a running list of the films I've loved across Tamil, English and Telugu cinema. It started as a way to practice HTML and CSS, and grew into an actual watchlist I keep coming back to.

Each movie on the Movies page has a spot for you to type in your own view before you forget it.

This box uses position: static — the default flow, no offsetting. Everything above it (the little "est. 2026" tag) uses position: relative to nudge itself slightly out of place, and the round button in the corner of every page uses position: fixed so it stays put while you scroll.
